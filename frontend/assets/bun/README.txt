Put your bun images in this folder:
- bun_chest_open.png
- bun_chest_closed.png
- uncooked_bun.png
- cooked_bun.png

Recommended size:
- Bun chest sprites: 64 x 64 pixels
- Bun ingredient sprites: 32 x 32 pixels
- PNG with transparent background

The game can temporarily use text placeholders if an image is missing.
